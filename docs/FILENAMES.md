# H-Walker 실험 파일명 템플릿

**디자인**: 10 subject × 8 condition × 3 trial × 3 source = **720 files**

**양식**:
```
{date}_{condition}_{terrain}_{speed}_{project}_{subject}_{feat1}_{feat2}_{trial}.csv
```

- `date`       = 측정일 YYMMDD (피험자별 다름)
- `condition`  = `TD` (treadmill, 고정)
- `terrain`    = `level` (고정)
- `speed`      = `1.0` m/s (고정)
- `project`    = `H-Walker` (고정)
- `subject`    = `s01` … `s10`
- `feat1_feat2` = condition encoding (8 가지, 아래 표)
- `trial`      = `1`, `2`, `3`
- prefix       = `Robot` (없음) / `Loadcell_` / `Motion_`

## 8 Condition encoding

| # | feat1 | feat2 | 의미 |
|---|---|---|---|
| 1 | `none` | `normal` | baseline · 일반 보행 (no WB) |
| 2 | `none` | `WB` | baseline · WB only (보조 없음) |
| 3 | `prox` | `axial` | assist · prox-axial |
| 4 | `prox` | `radial` | assist · prox-radial |
| 5 | `mid` | `axial` | assist · mid-axial |
| 6 | `mid` | `radial` | assist · mid-radial |
| 7 | `dist` | `axial` | assist · dist-axial |
| 8 | `dist` | `radial` | assist · dist-radial |
